# Abandoned input: generated depth

This image was generated while exploring a paired color/depth sheet. The objective was then clarified: depth must be computed by **software from the original turnaround**, not painted by ImageGen.

The input is retained as an experiment record only. No generated-depth reconstruction was accepted or claimed. It consumed one generation call and does not add evidence to the software-depth results. Future tests use estimated depth maps with explicit confidence, camera and scale checks.
