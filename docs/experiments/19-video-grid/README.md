# Video-derived grid candidates

Selected silent frames from a user-supplied generated pear turnaround and actual renders of its automatically triangulated grid fragments. No audio, source video, raw model or hidden completion is included.

- `input-frames.png`: indexed unblended measurement frames.
- `software-tagged-cells.png`: automatically assigned candidate corner/cell IDs, not guaranteed physical identities.
- `candidate-geometry.png`: software projection with conditional check colors.
- `candidate-turntable.gif` / `actual-mesh-views.png`: actual unchanged 252-quad candidate mesh.
- `all-vs-supported.gif` / `.png`: same coordinates/cameras, all 252 candidates versus 11 quads with all corners passing conditional held-out checks. The supported subset is visibly sparse and remains unverified.

See [method, rejected camera fit and provenance](../../../experiments/video_grid/README.md). No blended presentation frame enters geometry.
